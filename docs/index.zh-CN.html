Solana RecurringEnglish部署

自托管 DOCKER 服务

为周期服务提供钱包支付。

一个用于一次性 USDC 支付、Solana 定期订阅，以及 LiteLLM 服务额度发放的自托管 Portal。

阅读部署指南

是什么

一套支付层，两种商品。

固定额度。 用户签署一次精确的 SPL Token 支付，获得固定服务额度。

周期服务。 用户一次批准订阅，Portal worker 每期扣款并刷新下游服务额度。

为什么

让商业、结算和服务各司其职。

Solana Recurring 负责钱包授权、支付验证、周期扣款和审计记录。LiteLLM 继续负责模型网关和 API key 服务。Docker image 运行在你的服务器、数据库和商户钱包上。

用户钱包->Portal + Solana->LiteLLM 服务

如何部署

先在 Devnet 测试，再谨慎进入 Mainnet。

  1. 准备私有环境变量文件和 PostgreSQL 数据库。
  2. 运行固定版本的 Docker image。
  3. 配置管理员、商户钱包和代币。
  4. 在 Devnet 测试固定支付和周期 Plan。
  5. 验证完成后，使用官方 USDC 重新发布 Mainnet Plan。
查看 Devnet 和 Mainnet 步骤 ->

PORTAL

由用户明确批准钱包操作。

浏览器使用 Phantom、Solflare 或 Backpack 等 Wallet Standard 钱包。支付发放服务额度前，必须由服务端验证链上交易。

LITELLM

支付不等于模型服务。

周期扣款确认后，配置的 Provisioner 才会更新 LiteLLM 用户额度。LiteLLM 继续负责模型访问、用量和 API key。
