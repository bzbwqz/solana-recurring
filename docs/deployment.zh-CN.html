如何部署

先 Devnet，再用独立配置进入 Mainnet。

Docker image 同时运行 Portal 和 billing worker。GitHub Pages 只负责托管文档。

首次测试不要使用真实资金。 Devnet 使用如 tUSD 的测试 mint；Mainnet 使用 USDC，并且需要单独审核生产环境。

1. 准备服务器

使用 Linux 服务器或安装 Docker 的 Windows 主机。PostgreSQL 独立准备；应用只负责建表，不会创建数据库。

Linux

sudo install -d -m 700 /opt/solana-recurring
sudo install -m 600 /dev/null /opt/solana-recurring/portal.env
sudoedit /opt/solana-recurring/portal.env

Windows PowerShell

New-Item -ItemType Directory -Force C:\ProgramData\solana-recurring
notepad C:\ProgramData\solana-recurring\portal.env

2. 配置 Devnet

NODE_ENV=production
PUBLIC_BASE_URL=https://your-portal.example
DATABASE_URL=postgres://portal:CHANGE_ME@db-host:5432/portal?sslmode=require
SESSION_SECRET=生成一个足够长的随机值
ADMIN_EMAILS=admin@example.com
SOLANA_CLUSTER=devnet
SOLANA_RPC_URL=https://api.devnet.solana.com
TOKEN_MINT=YOUR_DEVNET_TEST_SPL_TOKEN_MINT
TOKEN_DECIMALS=6
TOKEN_SYMBOL=tUSD
MERCHANT_SECRET_KEY=仅限 Devnet 的服务端私钥
BILLING_ENABLED=true
PROVISIONER=noop

使用独立的 Devnet 商户和订阅用户钱包。商户钱包需要 Devnet SOL 支付手续费；订阅用户需要测试代币。只有准备好 LiteLLM 测试实例和专用管理员 key 后，才设置 PROVISIONER=litellm。

3. 运行 image

docker run -d --name solana-recurring --restart unless-stopped \
  -p 8080:8080 \
  --env-file /opt/solana-recurring/portal.env \
  ghcr.io/bzbwqz/solana-recurring:v0.1.0

Windows 使用 --env-file "C:\ProgramData\solana-recurring\portal.env"。打开 Portal，使用受邀管理员登录，发布短周期测试 Plan，并分别测试订阅和固定额度支付。

4. 进入 Mainnet

NODE_ENV=production
SOLANA_CLUSTER=mainnet-beta
SOLANA_RPC_URL=https://your-production-rpc.example
TOKEN_MINT=EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v
TOKEN_DECIMALS=6
TOKEN_SYMBOL=USDC
PROVISIONER=litellm
LITELLM_BASE_URL=https://your-litellm.example
LITELLM_ADMIN_KEY=仅服务端保存的专用 Key

使用生产 RPC、TLS、备份、Secret 管理、低余额商户热钱包和足够的 SOL 支付 worker 手续费。启用 ADMIN_WALLETS，并确保容器持续运行。

重要： Plan 账户绑定网络和 token mint。Devnet Plan 不能迁移到 Mainnet。切换网络或 mint 后，必须重新发布所有生产 Plan。

5. 理解支付流程

  • 固定额度：用户签署一次 USDC 直接转账；服务端验证收款方、mint、签名钱包、金额、确认状态和重放保护后，才发放额度。
  • 周期 Plan：用户只签署一次订阅授权；之后只有 Portal worker 发起 transferSubscription，再由 Provisioner 更新 LiteLLM。

未来可以增加 Solana Pay URL 作为二维码或移动钱包入口，但它不会替代当前 Portal 验证或 recurring Subscription PDA。
